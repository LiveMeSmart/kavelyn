# Kavelyn Starter Workflow

## 1. PLAN
Choose one bounded development goal. Avoid “build the whole application.”

## 2. BOUND
Fill the Basic Work Package before implementation:
- goal;
- context;
- scope;
- non-goals;
- acceptance criteria;
- tests;
- evidence;
- stop conditions.

If “done” cannot be checked, the task is not ready.

## 3. DELEGATE
Give the Work Package and only the necessary repository context to your coding agent.

Require it to stay in scope, run the required tests, return evidence and stop rather than improvise past a stop condition.

## 4. CHECK
Compare every acceptance criterion with concrete evidence.

Missing evidence is not PASS.

The Commercial Edition extends this loop with independent review/verification, bounded remediation, routing/escalation, Human Gates and structured handoff.
