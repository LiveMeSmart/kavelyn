# Kavelyn

**Your coding agent says “done.” Can you prove it?**

Kavelyn is a provider-agnostic workflow for turning software goals into bounded, testable work for AI coding agents.

Instead of delegating an open-ended request like:

> Add CSV export.

Kavelyn asks you to define the execution contract first:

**GOAL → SCOPE → NON-GOALS → ACCEPTANCE CRITERIA → TESTS → EVIDENCE**

Then you check the delivered work against that contract.

## Try Kavelyn Community

The Community Edition is free and intentionally small. It includes:

- a starter workflow;
- a Basic Work Package;
- a mini worked example.

Start with [STARTER-WORKFLOW.md](STARTER-WORKFLOW.md), then copy [templates/basic-work-package.md](templates/basic-work-package.md) into a real project.

## What Kavelyn is not

Kavelyn is not an autonomous coding platform or orchestrator. It does not execute agents, connect to providers, modify repositories or guarantee generated code is correct.

It provides the operating method and reusable artifacts for defining, delegating and checking agentic development work.

## Provider agnostic

The method is designed to be usable with different AI coding tools. That means methodological compatibility, not certified software integration with any particular provider.
